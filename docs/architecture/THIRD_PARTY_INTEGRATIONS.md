# Avaliação de integrações open source

Avaliado em 13/10/2026. Origens e licenças abaixo referem-se à documentação e metadados publicados pelos projetos; revisar novamente antes de integrar ou fixar uma versão de produção. Nenhum servidor terceiro foi instalado como processo adicional nesta M01.

O Nodaris fixa [MCP TypeScript SDK v2](https://github.com/modelcontextprotocol/typescript-sdk/releases) (`@modelcontextprotocol/server` 2.3.1, `@modelcontextprotocol/node` 2.1.1 e `@modelcontextprotocol/client` 2.3.1). O SDK v2 é a linha estável; os adaptadores têm versões independentes.

## Critérios

Para cada integração, comparar processo, pacote/biblioteca e implementação própria; fixar versão e origem; verificar licença, dependências e avisos de segurança; aplicar autorização Nodaris antes do encaminhamento; expor apenas a API Nodaris necessária. Uma anotação `readOnlyHint` não restringe capacidade do servidor.

Ver também [decisões](INTEGRATION_DECISIONS.md) e [segurança de terceiros](../security/THIRD_PARTY_SECURITY.md).
